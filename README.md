# GAgentX
Repository Containing all the details of the agent built during TDX 2025

Guardian Angel is an intelligent, compassionate AI agent accessible via mobile application. When a patient triggers an SOS, Guardian Angel initiates a seamless, automated workflow:
Instant AI Connection & Location: Establishes immediate communication and accurately captures the patient's GPS location and dispatch the ambulance.
Data Cloud - Unified Patient Story: Instantly accesses the patient's unified health profile from Salesforce Data Cloud, including critical allergies, pre-existing conditions, medications, and insurance details.
Intelligent Dispatch & Guidance: Mobilizes ambulance services and provides reassurance and guidance to the patient.
Proactive Hospital & Insurance Preparation: Alerts the hospital Emergency Department with a rich, data-informed patient summary and initiates preliminary insurance checks.
